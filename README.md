# Python Deadline Tracker

A Python and MySQL task management application developed for the S2-PFD200 Professional Development module as part of my FdSc Computing studies.

## Project Purpose

The purpose of this project was to improve my Python programming, database management, testing and problem-solving skills by developing a practical application for managing tasks and deadlines.

## Completed Features

- Add tasks with names, descriptions and deadlines
- View tasks stored in a MySQL database
- Edit existing tasks
- Delete tasks with confirmation
- Mark tasks as completed
- View completed tasks separately
- Calculate remaining days and display deadline warnings
- Identify overdue tasks
- Validate user input and handle invalid task IDs

## Technologies Used

- Python
- MySQL
- MySQL Connector for Python
- Visual Studio Code
- phpMyAdmin and XAMPP
- Git and GitHub Desktop
- Trello for project planning

## How the Application Works

The application runs in a terminal and displays a menu of task management options. Users select an option to add, view, edit, delete or complete tasks. Task information is stored in a MySQL database.

## Development and Testing

The project was developed gradually over five weeks. I used step-by-step guidance when learning unfamiliar programming concepts and tested features as they were implemented.

Testing included adding, editing, completing and deleting tasks, checking database records, validating task IDs and reviewing deadline warnings.

Screenshots of development and testing are stored in the Evidence folder. GitHub commits provide a record of project progress.

## Professional Development

This project helped me practise Python programming, SQL queries, database connections, error handling and testing.

It also highlighted areas where I need to improve, particularly writing code more independently, debugging and managing development time.

## Project Limitations

- The application uses a text-based interface rather than a graphical interface.
- It requires a local MySQL database.
- Further development would be needed before making it available to other users.
